# Barbearia Elite - Site Institucional

Site profissional para barbearia com agendamento via WhatsApp, desenvolvido em React com Tailwind CSS.

## 🚀 Tecnologias

- React 18
- Vite
- Tailwind CSS
- Lucide Icons (personalizados)

## 📦 Instalação

```bash
# Clone o repositório
git clone https://github.com/seu-usuario/barbearia-elite.git

# Entre no diretório
cd barbearia-elite

# Instale as dependências
npm install

# Inicie o servidor de desenvolvimento
npm run dev
